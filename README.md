# Breast-Cancer-Classification-system---AI
I have taken the Wisconsins Breast Cancer dataset as technical part of my Uni Assignment and created a AI classification system to predict if its Malignant or Bengin. This is a project Ive documented on Healthcare and how AI has assisted countless times in such critical predictions.

## How the classification system works ✨
The system classifies tumours as malignant or benign 
using the Wisconsin Breast Cancer dataset(available on the Kaggle site), with a focus on maximising recall for malignant cases

## What This Project Does
- Compares four classification algorithms (Random Forest, Decision Tree, 
  Logistic Regression, KNN) on a real medical dataset
- Engineers new features derived from clinical pathology logic 
  (compactness index, concavity-symmetry ratio, etc.)
- Modifies and tunes a Random Forest classifier to improve performance 
  over the baseline system
- Benchmarks improvements using accuracy, AUC-ROC, and malignant recall 
  across 5-fold cross-validation
